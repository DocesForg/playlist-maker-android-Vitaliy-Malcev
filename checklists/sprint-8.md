# Список задач для самопроверки:

Приложение успешно компилируется и работает на эмуляторе.
Запуск приложения происходит с экрана, содержащего меню для перехода к разделам Songs, Playlists, Favorites.
При переходе на экран Songs отображается строка поиска. При вводе текста начинается поиск треков по запросу. Во время поиска показывается индикатор загрузки. После завершения поиска индикатор исчезает, и отображается список найденных треков или сообщение об отсутствии результатов.
При клике на трек открывается экран с детальной информацией о композиции. На этом экране, помимо данных о треке, присутствуют кнопки для добавления в «Избранное» и в существующий плейлист.
Экран создания нового плейлиста позволяет задать название и описание, а также содержит кнопку для сохранения в хранилище.
