# Список задач для самопроверки:

Переходы между экранами приложения работают стабильно, без сбоев.
Логика навигации полностью сосредоточена в классе PlaylistHost.
Кнопка «Songs» открывает экран поиска.
Кнопка «Settings» открывает экран настроек.
При добавлении новых экранов требуется своевременное обновление навигационного кода.
