# Список задач для самопроверки:

## Экран поиска
Плейсхолдер (нет результатов). Если после успешного выполнения поискового API-запроса не найдено ни одной аудиозаписи, на экране «Поиск» отображается заглушка с сообщением об отсутствии результатов.
Плейсхолдер (ошибка сервера). Если поисковый API-запрос завершился ошибкой (сервер вернул код ошибки), на экране «Поиск» показывается изображение-заглушка с сообщением об ошибке сервера и кнопка «Обновить».
Нажатие на кнопку «Обновить». Если на экране «Поиск» отображается плейсхолдер с кнопкой «Обновить», то при нажатии на неё приложение повторяет последний неудачный поисковый запрос.
Непустой результат запроса. Если в результате успешного выполнения поискового API-запроса сервер вернул хотя бы одну композицию, на экране «Поиск» отображается список найденных треков.
Элемент списка результатов. При получении непустого результата на экране «Поиск» отображается список треков, где каждый элемент содержит:
- область для обложки;
- название трека (параметр trackName);
- имя исполнителя (параметр artistName);
- продолжительность в формате mm:ss (отформатированный параметр trackTimeMillis).
В качестве обложки используется изображение из параметра artworkUrl100.
Плейсхолдер обложки трека. Если у трека отсутствует изображение обложки, в области для обложки отображается заглушка.
Если обложка есть, но ещё не загружена, также показывается изображение-заглушка.
Изображение обложки трека. Если обложка присутствует и успешно загружена, она отображается в соответствующей области.
Нажатие на кнопку «Очистить поисковый запрос». Если пользователь находится на экране «Поиск» с непустым запросом и видит список треков, то при нажатии на кнопку очистки поисковый запрос сбрасывается, клавиатура скрывается, а кнопка (x) и список треков исчезают.

## Экран плейлиста
Размер и расположение элементов соответствуют дизайн-макету из Figma.
Отображаются данные:
- название плейлиста,
- описание плейлиста,
- список треков.
Реализована корректная навигация между экранами:
- При нажатии на плейлист в списке пользователь переходит на экран этого плейлиста.
- При нажатии системной кнопки «Назад» осуществляется возврат к списку плейлистов.
