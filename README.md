# playlist-maker-android-MalcevVitaliy

Проект для обучения разработке мобильных приложений

## История версий

### v3.0 - Спринт 3
Разработан основной экран MainActivity согласно дизайн-макету.
Добавлены SettingsActivity и SearchActivity с реализацией навигации между ними.

### v4.0 - Спринт 4
Выполнена вёрстка интерфейсов поиска и настроек.
Настроена работа кнопок в разделе настроек.
Логика переходов между экранами вынесена в класс PlaylistHost.

### v5.0 - Спринт 5
Организована эмуляция сервера, созданы слои Data и Domain.
Реализована работа репозиториев.

### v6.0 - Спринт 6
Внедрён ViewModel.
Создан полноценный интерфейс поиска музыкальных композиций с использованием архитектуры MVVM и Jetpack Compose.

### v7.0 - Спринт 7
Добавлен экран с плавающей кнопкой FloatingActionButton.
Реализовано отображение ModalBottomSheet.
Открытие нижней панели происходит по тапу на FloatingActionButton.

### v8.0 - Спринт 8
Ведена функциональность истории поисковых запросов.
Подготовлена структура для будущей работы с базой данных.
Осуществлена навигация на экран TrackDetails.
